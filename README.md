# Aeromática - Site Oficial

Repositório oficial destinado ao desenvolvimento e hospedagem do site institucional e promocional do projeto **Aeromática**.

---

## Sobre o Projeto

Este site foi desenvolvido para apresentar a proposta do jogo, disponibilizar o link para download, exibir a galeria de mídias e capturar cadastros/logins de usuários. O projeto faz parte de um projeto escolar com foco em unir os termos administração e matemática em um único jogo.
