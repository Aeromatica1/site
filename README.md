
# ✈️ Aeromática — Site Oficial

O **Aeromática** é um projeto interdisciplinar desenvolvido em 2026 pelos alunos do curso de Desenvolvimento de Sistemas (turma 331 DS, período vespertino).

Este repositório contém o código-fonte do site do projeto. Ele foi desenvolvido para apresentar o jogo, mostrar suas funcionalidades e reunir informações sobre o trabalho que estamos desenvolvendo.

## 🌐 Sobre o site

O site funciona como uma apresentação do Aeromática, permitindo que os visitantes conheçam a proposta do jogo e entendam um pouco melhor como ele funciona.

Entre os conteúdos disponíveis estão:

- **O Jogo:** apresentação do Aeromática e de sua proposta.
- **Matemática:** explicação de como os conceitos matemáticos fazem parte do jogo.
- **Mídia:** espaço dedicado aos conteúdos visuais do projeto.
- **Equipe:** apresentação dos integrantes responsáveis pelo desenvolvimento.
- **Download:** acesso para baixar o jogo.
- **Login:** área de acesso dos usuários.
- **Torre de Controle:** demonstração interativa em que é possível ajustar as pistas e a fila de voos, buscando equilibrar o tempo de espera e o lucro do aeroporto.

## 🛠️ Tecnologias utilizadas

Durante o desenvolvimento, utilizamos diferentes tecnologias para construir o frontend e o backend do site.

| Tecnologia | Utilização |

## 🎨 Identidade visual

Procuramos manter o visual do site relacionado ao tema do jogo, utilizando elementos inspirados na aviação e no ambiente dos aeroportos.

A ideia é que o site tenha uma identidade própria, mas que ainda combine com o jogo, mantendo uma ligação visual entre os dois.

## 🎮 Sobre o jogo

O Aeromática é um jogo de simulação e administração de aeroportos desenvolvido na Godot Engine.

Nele, o jogador fica responsável por administrar seu próprio aeroporto, gerenciando recursos, organizando operações, definindo destinos e melhorando a estrutura para atender cada vez mais passageiros.

A matemática também faz parte da experiência. Durante o jogo, o jogador precisa resolver problemas e desafios para conseguir recompensas, melhorar seu aeroporto e desbloquear novos recursos.

O jogo possui visual em pixel art e perspectiva top-down.

## 🏗️ Organização dos projetos

O Aeromática é dividido em dois repositórios principais:

| Repositório | Responsabilidade | Tecnologias |
|---|---|---|
| Jogo | Desenvolvimento das mecânicas e da experiência de jogo | Godot Engine |
| Site | Apresentação do projeto e funcionalidades web | HTML, CSS, JavaScript, React, JSX e Spring Boot |

Apesar de estarem separados, os dois repositórios fazem parte do mesmo projeto interdisciplinar e foram desenvolvidos pela mesma equipe.
